## 🦊 開発スタンス

私は **Firefox が好き** なので、この拡張もまず Firefox 向けに作りました。  
Mac + Firefox + ChatGPT（マイGPT含む）環境で動作保証しています。

もし同じ環境の方がいたら、ぜひこのアドオンを使ってみてください。  
そして、もし修正や改善、ドキュメント整理などをしてくださる方がいれば、**IssueやPull Requestをぜひお願いします！**

> さらに、**Chrome拡張版の需要** があれば、派生開発にも協力したいです。  
> Forkした場合は、ぜひ共有してもらえると嬉しいです。

## 💡 モチベーション

1. ChatGPTはチャットを「プロジェクト」でまとめられるのに、**マイGPTはなぜか対象外**だったため、独自に柔軟な体系整理をしたかった  
2. ChatGPT側に **チャットのフォーク機能** が追加されたことで、関連スレッドをまとめたい需要が急増  
3. ChatGPTのUIは変化が激しく、この拡張が**いつ不要になるかわからない**が、それでも本家に吸収されないよう頑張りたい  
4. 画像生成などで **テキストボックスの内容を再利用したい**場面が多い  
5. **Command + Return** による安全な送信ショートカットをサポート  
6. **UIは簡素に**、余計な機能は極力排除 
7. プロンプトを打つときにもう一つテキストエリアがあると便利

---

## ⚙️ 主な特徴

- 📁 お気に入り（フォルダ）によるチャット整理機能  
- 🧠 送信ショートカット  
  - `⌘ + Enter` → 送信  
  - `⌘ + Shift + Enter` → 送信してクリア  
- 🗂 フォルダの追加・削除・リネーム  
- 🧱 Sidepanel 完全対応（上下 6:4 レイアウト）  
- 🦊 Firefox + macOS + ChatGPT（マイGPT）環境での動作保証
