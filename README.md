# AIChat SmartSend＋

**AIChat SmartSend＋** は、ChatGPT / マイGPT に対して  
**Enter 暴発を防ぎ、Ctrl/Cmd + Enter を標準の送信キーに統一する拡張**です。

さらに、**Shift + Ctrl/Cmd + Enter** で  
「送信後もテキストを残す（再送しやすい）」モードを追加しています。

---

## 🎯 できること

- **Enter 単体では送信されない**（誤送信防止）
- **Ctrl/Cmd + Enter** → 普通に送信
- **Shift + Ctrl/Cmd + Enter** → 送信して、入力欄に内容を復元（再送・微調整に便利）

以上です。
UI や余計な設定はありません。
